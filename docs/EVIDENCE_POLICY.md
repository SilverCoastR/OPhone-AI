# Evidence policy

The public repository contains source, maintained documentation, and deterministic test fixtures. It does not contain:

- screenshots, screen recordings, or UI dumps from personal devices
- device serials, advertising identifiers, account names, phone numbers, email addresses, or local filesystem paths
- API keys, cookies, authorization headers, signed media URLs, or private endpoints
- APK history, intermediate builds, generated Gradle output, task logs, or diagnostic databases
- provider conversation exports or test data copied from real users

Release APKs belong in GitHub Releases. Local evidence may be used during development, but it must remain in ignored directories and be removed when no longer needed. Public bug reports should use synthetic examples and redact all credentials and identifying details.
