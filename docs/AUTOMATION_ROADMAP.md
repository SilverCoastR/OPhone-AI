# Automation roadmap

Current priorities for OPhone AI are:

1. Broaden physical-device coverage across Android and WebView versions.
2. Add provider adapters through the existing provider-neutral task interface.
3. Improve semantic UI targeting and structured outcome adapters for common Android intents.
4. Expand event sources while preserving task scope, acknowledgements, and privacy.
5. Add signed release builds, reproducible build metadata, and automated release checks.
6. Harden workspace quotas, network policy, credential redaction, and recovery evaluation.

New features should remain general-purpose capabilities. Website- or app-specific behavior belongs in model plans or reusable user programs, not hard-coded product workflows.
